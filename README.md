# 📈 Stock Market Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing stock market performance using **Power BI**.
The dashboard provides insights into stock price trends, trading volume, and overall market behavior.
It helps users understand historical stock performance and make data-driven decisions through interactive visualizations.

---

## 🎯 Objectives

* Analyze stock price trends over time
* Identify high-performing and low-performing stocks
* Visualize stock market movement using interactive dashboards
* Provide insights into trading volume and market fluctuations

---

## 🛠️ Tools & Technologies Used

* **Power BI** – Data visualization and dashboard creation
* **Excel / CSV Dataset** – Data source for analysis
* **Data Cleaning & Transformation** – Preparing data for visualization

---

## 📊 Dashboard Features

* 📉 **Stock Price Trend Analysis**
* 📊 **Trading Volume Visualization**
* 📅 **Time-based Stock Performance**
* 📈 **Comparison of Multiple Stocks**
* 🔍 **Interactive Filters and Slicers**
